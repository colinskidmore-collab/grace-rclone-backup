Privacy Policy — Grace Rclone Backup

Last updated: 16 November 2026

Grace Rclone Backup is a privately operated backup configuration using the open-source rclone software.

The application accesses the owner's Google Drive account with their permission to upload, organise, retrieve and manage backup files.

Files are transferred between the owner's computer and Google Drive using rclone. This website does not collect, receive or store backup files or OAuth credentials.

The operator does not sell personal information or use Google Drive data for advertising.

The owner controls backup retention and can revoke Google Drive access at any time.
