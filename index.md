# Grace Rclone Backup

Grace Rclone Backup is a personal backup configuration using the open-source rclone application to transfer files from a local computer to the owner's Google Drive account.

## Purpose

The application is used solely by its owner for personal backup management, including incremental backups and file version retention.

## Google Drive Access

Google Drive access is authorised by the account owner through Google's OAuth authentication process.

The application requires access to Google Drive to upload, organise, retrieve and manage backup files.

## Data Handling

Backup files are transferred directly between the owner's computer and Google Drive using rclone. This GitHub Pages website does not receive, store or process backup files.

The application is not offered as a public service.
