# Privacy Policy — Grace Rclone Backup

**Last updated: 16 November 2026**

## Overview

Grace Rclone Backup is a privately operated backup configuration using the open-source rclone software. It is intended for use by its owner and is not offered as a public service.

## Information accessed

The application requests Google Drive access to upload, organise, retrieve and manage backup files.

Access is granted through Google's OAuth authentication process and can be revoked by the account owner.

## Data storage and transfer

Files are transferred between the owner's computer and the owner's Google Drive account using rclone.

The GitHub Pages website does not collect, receive or store backup files, Google Drive contents or OAuth credentials.

## Information sharing

The operator does not sell personal information or use Google Drive data for advertising.

Files may be processed by Google Drive and rclone as necessary to provide the backup functionality.

## Data retention

Backup files and previous versions are retained according to the owner's configured backup and retention settings.

The owner controls the deletion of backups and can revoke Google Drive access at any time.
